    技術：Python 3 / Discord API / Transformers / PyTorch

    Discord上で動作するLLMチャットボットを開発。

    2021年当時に公開されていたEleutherAIのGPT-Neo 1.3Bを、 Hugging Face TransformersおよびPyTorchを利用して自環境で動作させ、 Discord Botとして統合しました。

    当時のLLMエコシステムを調査し、公開モデルを取得して推論環境を構築し、 外部サービスに依存せずにチャットボットとして利用できる形に実装しました。
